# Shell00 - 42 School Project

This project contains the Shell00 exercises from the 42 School curriculum. Each exercise focuses on basic shell operations, file management, and command-line utilities.

## Project Structure

```
shell00/
├── ex00/           # File creation with specific properties
├── ex01/           # File permissions and groups
├── ex02/           # Symbolic links
├── ex03/           # Find command usage
├── ex04/           # File timestamps and listing
├── ex05/           # Git commit operations
├── ex06/           # Git ignore operations
├── ex07/           # Text manipulation
├── ex08/           # Magic numbers and file operations
└── ex09/           # File type magic
```

## Exercises Overview

### ex00 - Z
Creates a file named 'z' containing 'Z' with specific permissions (404).

### ex01 - testShell00.tar
Creates a tar archive containing directories with specific permissions:
- test0: 715
- test1: 714  
- test2: 504
- test3: 404
- test4: 401
- test5: 644
- test6: 503

### ex02 - Oh yeah, mooore...
Creates a symbolic link 'sh1' pointing to `/goinfre/byoung-p/day00/test`.

### ex03 - SSH me!
Script that finds all .sh files and displays their names without the .sh extension.

### ex04 - MAC
Command that lists files with modification time in a specific format using `ls -ltm`.

### ex05 - Can you create it ?
Script that displays the last 5 commit hashes from git log.

### ex06 - Skip
Script that lists all ignored files using git ls-files.

### ex07 - Diff
Contains a text file with Star Wars themed content for diff operations.

### ex08 - Clean
Contains a file with magic number operations.

### ex09 - Illusions, not tricks, Michael...
Magic file for file type detection.
